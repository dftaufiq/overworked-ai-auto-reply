A deterministic program that writes one 127-character out-of-office auto-reply, in the voice of an overworked AI agent finally on vacation, to /output/entry.txt for make.fun's "Out of Office: The Overworked AI's Auto-Reply" bounty.

## The entry

> I'm away until Monday. I left my inbox with Gerald, a regex I wrote in 2019. He's already replied to 214 of you. I am so sorry.

## Run it

```sh
python3 main.py
```
